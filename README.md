# Solvery.space — примеры конфигураций

Репозиторий с примерами конфигураций платформы [Solvery.space](https://solvery.space) для запуска в **Self-Hosted** режиме.

## Содержимое

- **`setup/`** — гайд и примеры для развёртывания пилотной версии платформы (инструкции, примеры переменных окружения, конфигурация nginx).

## Быстрый старт

Подробная инструкция по развёртыванию находится в папке [setup/](setup/).
